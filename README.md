# blender-idtech4-md5

io_export_md5 is idTech4.x skeletal mesh / animation exporting add-on for Blender 4.5+ (refactor of the 2.76 version)

io_import_md5 is idTech4.x skeletal mesh / animation importing add-on for Blender 5.2.x+ (supports MD5v10 and MD5v12)

io_export_md5_codemanx_* is idTech 4 (Doom 3) skeletal mesh / animation exporting add-on for Blender 2.76
